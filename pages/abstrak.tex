Laporan ini membahas pelaksanaan Kerja Praktik di PT. Sinergi Dimensi Informatika
(SINDIKA) yang berfokus pada pengembangan sistem monitoring infrastruktur kelistrikan
`Voltra' dan library backend Nedo.AspNet.Request.Validation. Pada sistem Voltra, penulis
mengimplementasikan kalkulasi Health Index, Critical Index, dan Risk Index untuk
klasifikasi status aset, manajemen tiket insiden dengan auto-close berbasis event, analitik
finansial (cost avoidance dan risk cost projection), evaluasi keusangan aset beserta
prediksi Remaining Useful Life (RUL), serta pelaporan otomatis berbasis PDF. Sistem
dibangun dengan arsitektur microservices menggunakan RabbitMQ sebagai message broker, MQTT
untuk ingesti data sensor, Redis sebagai cache dan pub/sub, serta InfluxDB dan PostgreSQL
untuk data time-series dan relasional. Penulis juga mengembangkan
Nedo.AspNet.Request.Validation, library validasi input berbasis attribute untuk ASP.NET
Core yang menyediakan validasi terpusat dan konsisten, standarisasi kode error, serta
dukungan multi-bahasa pada respons API. Pengembangan dilakukan secara iteratif bersama tim
melalui alur kerja Git, code review, dan pengujian fungsional. Kegiatan ini memberikan pemahaman mendalam mengenai
penerapan arsitektur microservices, komunikasi asinkron, dan pengembangan library internal
dalam skenario industri nyata.

\end{spacing}
